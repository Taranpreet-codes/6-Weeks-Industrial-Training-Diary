- Tokens

- Token-Based Processing
- Context Window
- Efficient Prompt Design

## Learning Summary

On the tenth day of the training, our mentor introduced us to several important concepts that influence the behavior and performance of Large Language Models (LLMs). The session began with **Temperature**, a parameter that controls the randomness of AI-generated responses.

We learned that lower temperature values produce more consistent and deterministic responses, making them suitable for factual or technical tasks. Higher temperature values encourage the model to generate more creative and diverse responses, which are useful for brainstorming, storytelling, and content generation. The mentor explained that temperature does not increase the intelligence of the model; it only changes how responses are generated.

The session then focused on **Tokens**, which are the basic units processed by Large Language Models. We learned that text is divided into tokens before being processed by the model. The mentor explained the difference between input tokens and output tokens and discussed how token usage affects processing efficiency and API billing. We also understood the importance of writing concise prompts to reduce unnecessary token consumption.

Another important topic covered today was the **Context Window**. We learned that the context window represents the amount of information an AI model can consider while generating a response. A larger context window allows the model to process longer conversations and larger documents more effectively. The mentor also explained that when the context limit is exceeded, older information may no longer be considered unless external retrieval techniques are used.

Throughout the session, the mentor emphasized that understanding temperature, tokens, and context windows helps developers build more efficient, accurate, and cost-effective AI applications.

## Key Takeaways

- Temperature controls the creativity and randomness of AI responses.
- Tokens are the fundamental units processed by Large Language Models.
- Both prompts and generated responses consume tokens.
- Context Window determines how much information the model can remember during a conversation.
- Efficient prompt design helps reduce token usage and improves AI performance.

## Outcome

By the end of the tenth day, I developed a clear understanding of Temperature, Tokens, and Context Window in Large Language Models. I learned how these concepts influence response quality, efficiency, and resource utilization, providing valuable knowledge for developing effective AI-powered applications.
